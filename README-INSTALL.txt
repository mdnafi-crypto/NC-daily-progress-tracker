NC Progress App V5.1
====================

Install on Android:
1. Extract this ZIP.
2. Upload every file in this folder to the same folder on an HTTPS static host (for example, your GitHub Pages repository).
3. Open the HTTPS site in Chrome.
4. Open Chrome's menu (⋮) and choose Install app / Add to Home screen.

V5.1 features (includes all V5 features):
- Animated NAFI × CGPT → NC → PROGRESS APP intro.
- Mobile-first interface with Today, Plan, Insights, Calendar, History and Settings.
- Service worker is registered automatically on HTTPS hosting; updated app shell is cached for offline use.
- Recurring tasks are generated from the original template only, with duplicate legacy occurrences consolidated.
- Add task button on desktop and floating + button on mobile.
- Task check-in: Start/Continue timer, 50%, 70%, Full time, custom actual minutes, Done and Not done.
- Personal Emergency with an optional explanation. Explained emergencies reduce their negative effect on the completion score; an explanation can be edited for 8 hours.
- Analytics for 7-day week, 15 days, 30-day month, and a custom From-to date range.
- Daily tracker for Fajr, Dhuhr, Asr, Maghrib and Isha, with editable start/deadline windows and reminders.
- Optional Chasht tracker, separate from the five obligatory prayers and without default reminders.
- Calendar, history, date comparison, dark mode, task notifications, JSON backup/restore and CSV export.

Data is stored locally in the browser on this device. Export a JSON backup regularly. Importing a backup replaces current local data.

Notification limitation: browser reminders are most reliable while the app is open. Android may pause background timers or notifications depending on battery and browser settings.
